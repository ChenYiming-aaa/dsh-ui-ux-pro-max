Defer Await

React Async Waterfall React/Next.js

应该

Move await operations into branches where they're needed

if (skip) return { skipped: true }; const data = await fetch()

不要

Await at top of function blocking all branches

const data = await fetch(); if (skip) return { skipped: true }
致命

Promise.all Parallel

React Async Waterfall React/Next.js

应该

Use Promise.all() for independent operations

const [user, posts] = await Promise.all([fetchUser(), fetchPosts()])

不要

Sequential await for independent operations

const user = await fetchUser(); const posts = await fetchPosts()
致命

Dependency Parallelization

不要

Wait for unrelated data before starting dependent fetch

const [user, config] = await Promise.all([...]); const profile = await fetchProfile(user.id)
