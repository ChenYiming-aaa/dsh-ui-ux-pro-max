怎么用

左边选产品类型，右边给出这一类的完整配方。可以在结果里切换导出格式，直接复制到项目里。

配方是起点不是终点：风格名点开能看到具体长什么样，再决定要不要用。

结果包含

  • 主推与次选风格
  • 16 个配色令牌
  • 字体配对
  • 落地页结构
  • 决策规则与反模式
  • CSS / Tailwind / JSON 导出
