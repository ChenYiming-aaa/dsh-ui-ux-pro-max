Apple 原生体验Apple Native Experience

系统字体与语义色优先，8pt 间距、分组列表与平台化导航，明暗自动适配、克制而有目的的过渡。强调内容层级与无障碍，而非液态玻璃或装饰性模糊。

典型场景iOS / macOS 应用 · 设置与表单 · 系统工具

效果与动效

Content-first hierarchy, system typography roles, 8pt-aligned spacing, restrained borders and shadows, platform-appropriate corner radii, SF Symbols-style consistent icons, adaptive light/dark appearance, purposeful 150-300ms transitions, reduced-motion and reduced-transparency fallbacks

配色方案

主色 / Primary

Adaptive system backgrounds and grouped surfaces; semantic accent, label, separator, fill, and destructive colors; avoid hard-coded appearance assumptions

辅色 / Secondary

Secondary and tertiary labels, grouped content surfaces, control fills, accessible accent states, light/dark semantic mapping

强调色在页面底色上的对比度约 3.6:1，适合大字与图形，正文需另配深色。

适用场景

适合 / Best For

  • Native-feeling phone
  • tablet
  • and desktop apps
  • productivity tools
  • settings
  • forms
  • lists
  • media and utility products
  • responsive web apps adopting platform-aware behavior

避开 / Do Not Use For

  • Liquid Glass as the defining visual treatment
  • visionOS spatial interfaces
  • decorative blur or gradients
  • dense dashboards needing unrelated platform conventions
  • or web layouts that must behave identically on every platform

实现要点

落地清单

  • Use semantic roles for navigation bars, tab bars, sidebars, toolbars, buttons, segmented controls, toggles, text/search fields, sheets, popovers, menus, alerts, lists, and grouped content
  • preserve safe areas
  • provide keyboard and screen-reader semantics
  • verify light/dark contrast
  • test phone, tablet, desktop, reduced motion, and reduced transparency

CSS / 技术关键词

system-ui, -apple-system, BlinkMacSystemFont, SF Pro, SF Symbols, semantic color tokens, color-scheme: light dark, env(safe-area-inset-*), :focus-visible, @media (prefers-reduced-motion), @media (prefers-contrast), min-width: 44px, border-radius: 10-16px, transition: 150-300ms ease-out

AI 提示词

Design an Apple Native Experience interface with system typography, semantic adaptive colors, platform-aware navigation, accessible controls, grouped lists, sheets, popovers, purposeful transitions, and responsive behavior across phone, tablet, desktop, and web. Do not require Liquid Glass, blur, or gradients.
