风格描述

近黑分层（#020203→#0a0a0c）+ 微弱环境光斑，标题用 Inter 紧字距，主色 #5E6AD2。像影院一样把内容推到前景。

关键词

dark modecinematicambient lightglassmorphismdeep blackindigoglowbluratmosphericreanimatedhapticpremiumlayeredfrosted glasslinear gradient

效果与动效

Expo.out Bezier(0.16,1,0.3,1) easing; spring modals (damping:20 stiffness:90); haptic-linked press (Impact Light/Medium); animated ambient light blobs (Reanimated translateX/Y slow oscillation); BlurView glassmorphism headers/nav (intensity 20); scale press 0.97 → 1.0; avoid pure #000000 (OLED smear)

配色方案

色值取自风格数据，不足时补充主题令牌

主色 / Primary

Deep #020203, Base #050506, Elevated #0a0a0c, Accent #5E6AD2

辅色 / Secondary

Foreground #EDEDEF, Muted #8A8F98, Accent Glow rgba(94 106 210/0.2), Border rgba(255 255 255/0.08), Surface rgba(255 255 255/0.05)

强调色在页面底色上的对比度约 4.3:1，适合大字与图形，正文需另配深色。

适用场景

适合 / Best For

  • Developer tools
  • pro productivity apps
  • fintech/trading dashboards
  • media/streaming platforms
  • AI tool interfaces
  • high-end gaming companion apps

避开 / Do Not Use For

  • Consumer apps needing warmth
  • children's apps
  • health/medical contexts where dark feels harsh
  • high-accessibility contexts needing maximum contrast

实现要点

落地清单

  • No pure #000000 backgrounds,
  • LinearGradient base screen,
  • Animated ambient blobs (Reanimated, native driver),
  • BlurView on tab bar and headers,
  • borderRadius 16 on all cards,
  • Haptic feedback on every Pressable,
  • Bezier(0.16,1,0.3,1) easing used,
  • Accent glow behind primary button,
  • No solid grey borders (rgba only),
  • Bottom sheets replace all modals

CSS / 技术关键词

borderRadius: 16 (cards/buttons), background: LinearGradient #0a0a0f→#020203, border: StyleSheet.hairlineWidth rgba(255,255,255,0.08), BlurView intensity={20} tint='dark', useAnimatedStyle + withRepeat (blob oscillation), Easing.bezier(0.16,1,0.3,1), withSpring damping:20 stiffness:90, Haptics.impactAsync(ImpactFeedbackStyle.Light), scale: 0.97 press

衍生自 OLED 深黑 / Dark Mode (OLED)。
