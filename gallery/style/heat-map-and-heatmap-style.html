风格描述

用冷—暖连续色阶编码数值密度，读者一眼看出热点与空白。需要清晰的色阶图例，并避免用红绿单独承载正负含义。

--heatmap-hot#FF0000
--cell-size24px

配色方案

色值取自风格数据，不足时补充主题令牌

主色 / Primary

Gradient scale: Cool (blue #0080FF) to hot (red #FF0000), neutral middle (white/yellow)

辅色 / Secondary

Support gradients: Light (cool blue) to dark (warm red), divergent for positive/negative data, monochromatic options

强调色在页面底色上的对比度约 4.0:1，适合大字与图形，正文需另配深色。

适用场景

适合 / Best For

  • Geographical analysis
  • performance matrices
  • correlation analysis
  • user behavior heatmaps
  • temperature/intensity data

避开 / Do Not Use For

  • Linear data representation
  • categorical comparisons (use bar charts)
  • small datasets
