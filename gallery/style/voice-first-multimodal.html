风格描述

以波形、聆听脉冲与状态色表达「在听 / 在想 / 在说」，屏幕只做辅助确认。需要处理无视觉、弱网与打断等边界。

关键词

Voice UImultimodalaudio feedbackconversationalhands-freeambientcontextualspeech recognition

效果与动效

Voice waveform visualization, listening pulse, processing spinner, speak animation, smooth transitions

设计系统变量

--listening-color#6B8FAF
--speaking-color#22C55E
--waveform-height60px
--pulse-duration1.5s
--indicator-size24px
--voice-accent#9B8FBB

配色方案

色值取自风格数据，不足时补充主题令牌

主色 / Primary

Calm neutrals: Soft White #FAFAFA, Muted Blue #6B8FAF, Gentle Purple #9B8FBB

辅色 / Secondary

Audio waveform colors, status indicators (listening/processing/speaking), success/error tones

强调色在页面底色上的对比度约 3.3:1，适合大字与图形，正文需另配深色。

适用场景

适合 / Best For

  • Voice assistants
  • accessibility apps
  • hands-free tools
  • smart home
  • automotive UI
  • cooking apps

避开 / Do Not Use For

  • Visual-heavy content
  • data entry
  • complex forms
  • noisy environments
