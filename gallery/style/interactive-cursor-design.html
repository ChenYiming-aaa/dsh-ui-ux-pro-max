风格描述

光标成为界面的一部分：放大、磁吸、形变、拖尾与混合模式反色。趣味性强，但必须保留原生光标可用性与触屏降级。

关键词

Custom cursorcursor as toolhover effectscursor feedbackpointer transformationcursor trailmagnetic cursor

效果与动效

Cursor scale on hover, magnetic pull to elements, cursor morphing, trail effects, blend mode cursors, click feedback

设计系统变量

--cursor-size20px
--cursor-hover-scale1.5
--magnetic-distance100px
--trail-length10
--trail-fade0.1
--blend-modedifference

配色方案

色值取自风格数据，不足时补充主题令牌

主色 / Primary

Brand-dependent, cursor accent color, high contrast for visibility

辅色 / Secondary

Trail colors, hover state colors, magnetic zone indicators, feedback colors

强调色在页面底色上的对比度约 10.9:1，可用于正文与图标。

适用场景

适合 / Best For

  • Creative portfolios
  • interactive experiences
  • agency sites
  • product showcases
  • gaming
  • entertainment

避开 / Do Not Use For

  • Mobile-first (no cursor)
  • accessibility-critical
  • data-heavy dashboards
  • forms

实现要点

落地清单

  • Custom cursor works,
  • Hover morph smooth,
  • Magnetic pull subtle,
  • Trail performance ok,
  • Click feedback visible,
  • Touch fallback provided
